# Security

## Reporting a problem

If you find a security problem in the site or the code in this repo, please report it privately through GitHub's
private vulnerability reporting: open the **Security** tab of this repo and choose **Report a vulnerability**.

If that doesn't work for you, open a normal issue that says you have something to report, with no details in it,
and I'll reach out to set up a private channel.

Please include what you found, the steps to reproduce it, and what someone could do with it. I'll reply as soon as I
can and keep you posted while it gets fixed. If you'd like credit in the fix, say so.

## In scope

- The live site and everything it serves (pages, scripts, headers).
- The code in this repo: the engine, the site, the build and CI scripts, and the packages in `packages/` and `mcp/`.
- Dependencies, when the way this project uses them makes a problem reachable.

## Out of scope

- Reports from automated scanners with no working example.
- Anything that needs a compromised device, browser or extension.
- Denial of service by sheer traffic.

This is a personal project, so there is no bug bounty.
